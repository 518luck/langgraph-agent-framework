# app/core

适用：通用基础能力，例如日志、生命周期管理、请求上下文等。

## 必须

- 一个通用能力一个模块。

### 日志

- 格式、sink、轮转与保留只在本层配置一次；导出统一 `logger` 单例。
- 格式固定含时间、级别、request_id、调用位置、消息。
- 开关、级别、文件路径来自配置层，不硬编码。
- request_id 由本层统一注入，业务代码不手工传递。

### 请求上下文

- 请求级状态用 `ContextVar` 保存，并给默认值：无中间件的脚本场景照常可用。

## 禁止

- 引用业务层（`entities` / `models` / `repositories` / `services` / `clients`）：依赖单向。
- 业务模块内自行配置日志（sink、格式、文件路径、级别）。
- 用模块级全局变量保存请求级状态。
- 手工把 request_id 拼进日志文本。
