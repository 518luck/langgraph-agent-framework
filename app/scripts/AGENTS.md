# app/scripts

适用：工具脚本（命令行入口），例如初始化数据、同步外部数据源。

## 必须

- 一个任务一个脚本；只做入口与调度。
- 用模块方式执行：`uv run python -m app.scripts.<模块>`；在项目根目录运行。

### 入口

- `if __name__ == "__main__"` 内：解析参数 → 转 `Path` → `asyncio.run(...)`。
- 参数用 `argparse`；必需参数标 `required=True`；路径参数用 `Path`。
- 参数只表达"这次跑什么"，不带业务判断。

### 装配

- 顺序：初始化所需客户端 → 持有 session → 构造仓储 → 注入 service → 调 service 方法。
- 只把入口参数（如配置路径）传给 service；配置内容的解析归 service。
- 结束时关闭已初始化的客户端。

## 禁止

- 在脚本里写业务流程（读配置、组装实体、SQL、索引写入）：归 service。
- 依赖启动目录或绝对路径定位文件。
- 顶层模块代码里执行任务：放进 `__main__` 或函数内。
- 新增客户端或仓储后遗漏同步：`init()` / `close()` / 构造注入。
